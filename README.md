# Netflix Clone

Netflix uygulamasının temel akışlarını ve kullanıcı arayüzünü taklit eden bir React Native projesi.

Bu proje, mobil arayüz geliştirme, component yapısı ve ekran bazlı mimariyi göstermek amacıyla geliştirilmiştir.

## Screens
- Home Screen
- Movies / Series Listing
- Movie Detail Screen
- Search Screen

## Features
- Netflix benzeri ana sayfa tasarımı
- Film ve dizi listeleme
- Detay ekranı
- Arama ekranı
- Component bazlı mimari
- Dummy data kullanımı

## Tech Stack
- React Native
- TypeScript
- Expo
- React Navigation

## Project Structure
- `src/screens` – Uygulama ekranları
- `src/components` – Tekrar kullanılabilir bileşenler
- `src/service` – API / data işlemleri
- `src/store` – State management yapısı
